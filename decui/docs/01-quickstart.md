# Быстрый старт

## Установка

```bash
pip install PySide6 sqlalchemy pyinstaller
```

## Запуск демо-примера

```bash
cd F:/projects/decui
python examples/simple.py
```

При первом запуске автоматически создадутся 3 товара и 1 счёт с тремя позициями.

## Что вы увидите

```
ERP Система
├── Справочники → Товары       — список, кнопки: Новый / Изменить / Удалить
├── Документы   → Счета        — табличная часть, Рассчитать / Провести
└── Отчёты      → Список товаров, Продажи
```

## Минимальный пример

```python
from decui import catalog, Catalog, String, Decimal as D

@catalog
class Product(Catalog):
    name  = String("Наименование", required=True)
    price = D("Цена", precision=10, scale=2, required=True)
```

Всё остальное (SQL, форма, список, навигация) фреймворк генерирует сам.

## Документация по разделам

## Пример «Вундеркинд»

```bash
python examples/vunderkind.py
```

Центр развития детей: возрастные интервалы, кружки, преподаватели,
расписание с проверкой пересечений, отчёт с фильтрами. Демо-данные
создаются автоматически при первом запуске.

## Пример «Simple»

```bash
python examples/simple.py
```

Товары, счёт с табличной частью, авто-расчёт сумм, отчёты.
