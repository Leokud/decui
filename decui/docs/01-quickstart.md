# Быстрый старт

## Установка

Откройте корень репозитория DECUI. Для запуска из исходников нужны Python 3.12+
и uv. Команды в этом уроке одинаковы в Bash и PowerShell.

```bash
uv sync --locked --inexact
```

Если DECUI уже установлен в активном окружении Python 3.12+, выполняйте
команды `decui` и `python` без префикса `uv run --locked`.

## Карточка товара

Из корня репозитория создайте учебный проект и откройте приложение.

```bash
uv run --locked decui new warehouse --template basic
cd warehouse
uv run --locked decui run
```

В открывшемся списке «Товары» нажмите «Новый», введите «Чай» и цену 125,50,
затем сохраните карточку. Закройте приложение и повторите команду запуска.
Товар останется в списке, потому что запись хранится в `warehouse/data.sqlite3`.

Нажмите `Ctrl+F`, введите «Чай» и нажмите `Enter`, чтобы перейти к
результатам. Ещё одно нажатие `Enter` открывает выбранную карточку.
В поле поиска `Esc` очищает строку. Кнопка «Сбросить» также снимает
отбор по полям. При обновлении через `F5` список сохраняет выбор, если
запись по-прежнему видна.

Измените цену в карточке и нажмите `Ctrl+S` (`⌘S` на macOS), чтобы
сохранить запись и продолжить работу в карточке. Если закрыть окно
или перейти к другому разделу с несохранёнными правками, DECUI предложит
сохранить их, выйти без сохранения или продолжить редактирование.

Откройте `app.py` и посмотрите, как описан справочник.

- `@master_data` регистрирует класс `Product`. DECUI создаёт для него таблицу SQLite, список и карточку.
- `name = String("Наименование", required=True)` добавляет обязательное текстовое поле. `price = Decimal("Цена", scale=2, min_value=0)` добавляет цену с двумя знаками после запятой.
- `ERPApplication(..., start=Product)` открывает список товаров при запуске.

## Добавьте поле

Импортируйте `Integer` из `decui` в `app.py`. Добавьте строку в класс
`Product` рядом с `name` и `price`.

```python
    priority = Integer("Приоритет", default=3)
```

Перезапустите приложение из каталога `warehouse`. Откройте карточку «Чай»,
задайте приоритет 5 и сохраните. Создайте ещё один товар. В новой карточке
начальный приоритет равен 3. DECUI добавляет столбец к существующей таблице,
поэтому у «Чая» сохраняются прежние название и цена.

После закрытия окна проверьте, что схема создаётся и товар сохраняется
через Python API.

```bash
uv run --locked decui check
uv run --locked decui test -q
```

`decui check` проверяет схему в памяти. Тест из `test_app.py` создаёт свою
базу в памяти, сохраняет товар через `db.save()` и читает через `db.get()`.
Созданный шаблоном `.gitignore` исключает локальный `data.sqlite3` и его журналы из Git.

## Шаблон приложения заказов

Из корня репозитория создайте проект с товарами, клиентами, заказами и отчётом.

```bash
uv run --locked decui new my_orders --template orders
cd my_orders
uv run --locked decui test -q
uv run --locked decui run
```

Тест шаблона проводит заказ через `db.post(order)` и проверяет, что в базе
сохранились признак проведения и сумма строки. Отчёт читает заказы через
`db.filter(..., date__date_range=(date_from, date_to), include_table_parts=True)`
и считает итоги по сохранённым строкам. [Команды CLI](12-dx-guide.md#1-консольная-утилита-decui-cli)

## Упражнение с заказами и отчётом

1. Сохраните товар с приоритетом в первом проекте `warehouse` и закройте окно.
2. Сохраните [полный пример](../../examples/features/purchase_orders.py)
   рядом с `app.py` под именем `purchase_orders.py` и запустите из каталога
   `warehouse` командой `uv run --locked python purchase_orders.py --demo --db data.sqlite3`.
   Пример использует сохранённый товар и добавляет два заказа с ценами на дату заказа.
3. Откройте «Закупки по строкам». За 01–30.11.2026 ноябрьский заказ
   от 30 ноября в 23:59:59 даст 25,00 (2 × 12,50). Расширьте диапазон до
   01.01.2027, чтобы увидеть январский заказ второго поставщика с суммой 0,00.
   Период за октябрь пуст. Перевёрнутый диапазон покажет ошибку.
4. Откройте поставщика «Север» и создайте заказ в списке «Заказы поставщику».
   Поле поставщика заполнится сразу. Добавьте строку с тем же товаром, задайте
   дату в декабре 2026 года и сохраните. Декабрьская цена за единицу равна 15,00.
   После перезапуска заказ виден у «Севера».
5. В карточке «Север» выберите «Отчёты → Закупки по строкам». Отчёт сразу
   сформируется с фильтром по «Северу». Укажите период до 01.01.2027 и нажмите
   «Сформировать». Январский заказ «Юга» появится после очистки фильтра
   «Поставщик» и повторного формирования. Дважды нажмите на строку, чтобы
   открыть заказ.

## Примеры из репозитория

Запускайте команды ниже из корня репозитория.

### «Вундеркинд»

```bash
uv run --locked python -m examples.vunderkind
```

Центр развития детей: возрастные интервалы, кружки, преподаватели,
расписание с проверкой пересечений, отчёт с фильтрами. Демо-данные
создаются автоматически при первом запуске.

### Адреса доставки

```bash
uv run --locked python -m examples.features.dependent_refs
```

Выберите покупателя в заказе и откройте поле адреса. Отбор по покупателю
и создание связанного адреса описаны в [руководстве по полям](02-entities.md#связанные-записи-и-зависимый-выбор-ссылки).

### «Simple»

```bash
uv run --locked python -m examples.simple
```

Товары, счёт с табличной частью, авто-расчёт сумм, отчёты.
