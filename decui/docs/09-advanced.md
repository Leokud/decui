# Прочие возможности

Остальные продвинутые функции, не вошедшие в отдельные документы.

---

## Роли и права

```python
from decui.sequence import define_role, has_permission, set_role

define_role("admin", ["full_access"])
define_role("manager", ["edit_price", "view_report"])

set_role("manager")
if has_permission("manager", "edit_price"):
    ...
```

---

## Автоматическая миграция схемы

При изменении полей сущностей (добавлении/удалении) БД пересоздаётся
автоматически при следующем запуске. Данные теряются.

Хеш схемы хранится в таблице `_erp_config`. При несовпадении — DROP ALL + CREATE ALL.

---

## Последовательность документов

```python
@document
class Invoice(Document):
    __sequence__ = True  # проверять хронологию при проведении
```

Проверка: если есть проведённый документ с более поздней датой,
проведение текущего блокируется.
